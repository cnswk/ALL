# ImageAll

화면을 보고 알아서 클릭해 주는 윈도우 자동화 프로그램입니다. 화면에서 찾을 그림을 등록해 두면, 그 그림이 나타났을 때 클릭·키 입력·대기 같은 동작을 대신 해 줍니다. 창을 최대 10개까지 각각 따로 돌릴 수 있고, 내 다른 컴퓨터를 원격으로 이어 쓰는 기능도 들어 있습니다.

## 3일 무료로 먼저 써 보세요

받아서 켜면 **3일 무료 체험**을 바로 신청할 수 있습니다. 결제 먼저 하지 않아도 됩니다.
써 보시고 마음에 들면 그때 정식으로 등록하시면 됩니다. (컴퓨터 1대에서 쓰는 프로그램입니다.)

## 이런 것을 할 수 있어요

- 화면에서 그림을 찾아 클릭하기 — 크기가 ±20% 달라지거나 살짝 돌아가 있어도 찾습니다
- 글자 읽기 — 화면의 숫자나 글씨를 읽어 조건에 씁니다
- 색깔 검사와 게이지 읽기 — 체력 막대 같은 것의 비율을 봅니다
- 움직임 감지 — 화면이 움직이는지, 멈췄는지 보고 기다립니다
- 동작 32가지 — 클릭·더블클릭·드래그·휠·키 입력·대기·반복·변수·소리·알림 등
- 녹화 — 내가 하는 클릭과 키 입력을 기록해서 그대로 만들어 줍니다
- 창 여러 개 동시에 — 최대 10개를 각각 따로 돌리거나, 한 창을 조작하면 다른 창이 따라 하게 할 수 있습니다
- 창 정렬 — 여러 창을 바둑판처럼 나란히 놓고 원래대로 되돌립니다
- 만들기 도우미 6가지 — 사냥, 채집, 따라가기, 사무 감시, 자동 입력, 숫자 감시
- 순서대로 실행 — 만들어 둔 작업 여러 개를 차례로 돌립니다
- 예약 실행 — 요일과 시각을 정해 두면 알아서 시작하고 멈춥니다
- 알림 받기 — 텔레그램이나 디스코드로 상황을 보내 줍니다 (화면 사진 첨부 가능)
- 백그라운드 입력 — 창을 앞으로 꺼내지 않고도 넣을 수 있습니다 (되는 프로그램에 한합니다)
- 안드로이드 에뮬레이터 — LDPlayer, MuMu 는 직접 터치를 넣는 방식도 씁니다
- 고급 스크립트 — 필요하면 Lua 나 자바스크립트로 직접 짤 수 있습니다
- 원격 지원 — 문제가 생기면 판매자가 화면을 보며 도와드립니다
- 내 다른 컴퓨터에 접속 — 집과 사무실 컴퓨터를 이어 쓸 수 있습니다
- 사용 설명서 19장이 프로그램 안에 들어 있습니다

## 필요한 환경

- 윈도우 10 (1809) 이상, 64비트
- 따로 설치할 것은 없습니다. 프로그램 안에 필요한 것이 다 들어 있습니다
- 인터넷 — 처음 켤 때 한 번 필요합니다. 그 뒤로는 7일까지 인터넷 없이 쓸 수 있습니다
- 실행할 때마다 관리자 권한 확인 창이 뜹니다 (다른 창에 입력을 넣으려면 필요합니다)

## 처음 실행할 때

**파란 창이 뜨면** — "Windows의 PC 보호" 라는 파란 창이 뜰 수 있습니다.
**추가 정보** 를 누르고 **실행** 을 누르시면 됩니다. 프로그램에 문제가 있는 것이 아니라, 아직 많이 받아 가지 않은 새 프로그램이라 윈도우가 한 번 물어보는 것입니다.

**관리자 권한 창이 뜨면** — **예** 를 누르시면 됩니다. 다른 창에 클릭과 키 입력을 넣으려면 필요한 권한입니다.

설치는 내 계정 폴더에 되므로 설치할 때는 관리자 권한이 필요하지 않습니다. 지울 때도 내가 만든 작업과 그림은 그대로 남습니다 (같이 지우고 싶으면 지울 때 선택할 수 있습니다).

## 알아 두실 것

- 원격 지원은 기본으로 **매번 물어보게** 되어 있고, 연결 중에는 화면 맨 위에 빨간 띠가 떠서 바로 끊을 수 있습니다
- 새 버전이 나오면 알아서 받아 설치합니다. 작업이 도는 중에는 설치하지 않습니다
